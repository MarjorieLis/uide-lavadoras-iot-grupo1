# Pruebas del proyecto

Aquí reunimos las instrucciones para comprobar que la simulación de la lavadora envía datos y avisa cuando el ESP32 se desconecta.

La [Guía GTA S5](GUIA_GTA_S5.md) explica cómo:

1. Iniciar el [proyecto en Wokwi](https://wokwi.com/projects/481853051628154881).
2. Recibir mensajes JSON en Ubuntu.
3. Autorizar un lavado de prueba y simular su inicio y final.
4. Detener Wokwi y observar `desconectado` mediante Last Will.

Las capturas de pantalla se toman durante la ejecución, mostrando la consola de Wokwi y la terminal de Ubuntu con los mensajes recibidos.
