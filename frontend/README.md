# Frontend — referencia visual

`index.html` es una **maqueta estática** para hablar del panel durante la revisión de arquitectura. No realiza pagos, no consulta la API y no envía comandos al ESP32.

La aplicación se conecta por **HTTPS (F1 y F9)**, mostrar la fecha del último estado y diferenciar una solicitud sin confirmar de una autorización confirmada.
